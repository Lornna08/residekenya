The GitHub connector currently supports creating and updating text files through the available actions, but this workflow has not provided a bulk binary upload or Git push operation. Do not interpret this starter repository as a complete transfer of the supplied 200 MB workspace.

The database dump is intentionally withheld from Git because it contains personal data, user records, activity logs and password hashes. Import it securely into a managed staging database later.
